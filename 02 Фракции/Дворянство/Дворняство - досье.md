# Дворянство — межмировой конклав беглецов

> _«Мы не творцы бедствий, мы выращиваем тех, кто способен их пережить.»_

---

## 1. Легенда и исходная гипотеза

 | Факт | Подробности | 
 | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | 
 | **Ядро организации** | 15–25 личностей, переживших крушение как минимум **трёх миров**. Каждый раз они «перескакивают» дальше, пользуясь экспериментальными путями (Тропы Ускользания). Из каждого мира добирают одного члена, лучшего из семи главных агентов. | 
 | **Общее прозвище** | «Дворянство» — удобный зонтичный бренд; в новом мире принимают форму уместной элиты (дворы, корпораты, роды). | 
 | **Преследователь** | Рабочее имя — «Бездна»; феномен, пожирающий реальности волной антиманы. Никто не знает, что именно это: космический разум, хаос самих миров, кара бога‑создателя. | 
 | **Тактика выживания** | 1) провоцируют **кризис средней силы**, 2) защищают выживших, 3) оставляют за собой «ущелье героев», надеясь, что Бездна «споткнётся» о массив сильных душ. |

## 2. Организационная структура

 | Ярус | Код‑роль | Функция | Примеры лиц | 
 | ----------------------- | ------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | 
 | **1. Верховный Круг** | _Примы_ (≤ 5) | стратеги, знают прямой путь к Тропам Ускользания. | пока неизвестны; возможно, один из королей соседних империй или глава мега‑корпы в киберпанке. | 
 | **1,5. Спящие** | _Резерв_ (~10) | основные члены дворянства, не участвующие в текущей операции, новобранцы могут быть на уровнях ниже | **Амораллис** — никак себя не выдаст и проживет всю жизнь в роли, если не раскрыть. | 
 | **2. Серебряные Маски** | _Кураторы_ (7‑10) | управляют региональными операциями, владеют «ключами» к порталам. | **Авель** — Куратор «Щита», не менее двух Масок скрыты в Великих Родах. | 
 | **3. Теневые Глашатаи** | _Сценаристы_ (≈ 20) | готовят кризисы: диверсии, шпионаж, атаки на ресурсы. | **Джек** (бывший 🗝 Catalyst‑Глашатай). | 
 | **4. Локальные Агенты** | _Слуги_ (десятки) | исполнители, финансисты, учёные, наёмники. | часть академиков Манретэнн, офицеры советской стражи, ряд попаданцев. |

## 3. География влияния

 | Мир/уровень | Опорные активы | Статус | 
 | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | 
 | **Хисуя (фэнтези+тех)** | Сердце города, место в Совете, теневой капитал в Манретэнн, 3 % храмовой сети Пантеона Света, большое влияние в Королевстве Пик и некоторых других людских регионах | _Критический узел_ |

 | **Предыдущий мир («Три Марша») ** | оставлены **«фортификации героев»**, активна линия сопротивления | _Отсечён, но ещё держится_ | 

> _Оценка радиуса власти:_ прямое доминирование — один город/мир; косвенное — до 5–6 соседних реальностей, связанные через Тропы.

## 4. Ресурсы

- **Портальные кисты** — мобильные «семена» Троп Ускользания (8 шт. → 5 задействованы).

- **Фонды Сквозных Активов** — золото, кредиты, мантовары, конвертируемые через скрытые биржи.

- **Кадровый резерв** — «коллекция героев»: личности с высоким потенциалом, которым Дворянство тайно помогает выжить.

## 8. Возможные сюжетные крючки

1. **Контратака Бездны** — первые скауты появляются в Хисуе; Дворянству нужен «герой‑детонатор» для ответа.

2. **Срыв Клятвы Ношоку** — если Великое Затмение пойдёт не по плану, богиня потребует от Дворянства раскрыть порталы.

3. **Охота за Джеком** — кто-то украл у него портальную кисту; Авель нанимает ПК, чтобы вернуть.

4. **Раскол Масок** — младшие члены считают метод «кризис+защита» бессмысленным; готовят собственный побег, жертвуя городом.

### TL;DR

**Дворянство** — мобильная элита‑беглец, выращивающая «героические бастионы» в каждом мире, чтобы оттянуть или сломать наступление некой Бездны. Их власть опирается на маски‑роли, скрытые капиталы и способность организовать управляемую катастрофу.
