# Работа с Хисуей

Перед изменениями прочитать `CODEX.md` и проверить `git status`. Это Obsidian-хранилище авторского мира с публичной версией на GitHub Pages.

- Сохранять авторский лор и источники. Различать сыгранные события, поздние состояния, черновики, планы и предложения нового ведущего. Несовместимые редакции не сводить в единый канон без решения автора.
- Новые справочные статьи должны ссылаться на исходные заметки. Не восстанавливать повреждённый текст догадками.
- Исходники редактируются в корне хранилища. `.site/content` и `.site/public` генерируются, правки в них не сохраняются.
- Не возвращать старый RPG-модуль как обязательную систему: пользователь отказался от его дальнейшего использования.
- Не включать в коммиты посторонние файлы, кеши и изменения пользователя автоматически. Добавлять в Git только файлы текущей задачи.
- Отдельный проект перевода Cortex находится в соседнем `Cortex-RU`; его материалы и доступ не смешивать с публичной Хисуей.
