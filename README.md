# Хисуя

Мир для новой ролевой кампании: справочник, исходные заметки, история прошлых игр и идеи для возвращения.

**Читать с телефона:** https://noty-chan.github.io/hisuya/

Вход в материалы — [Хисуя.md](Хисуя.md). Заметки в корне остаются обычным хранилищем Obsidian. Разделы `06 Справочник` и `07 Новая кампания` содержат обработанный материал; ранние версии сохранены отдельно и не становятся каноном автоматически.

## Как обновить сайт

Редактировать заметки как обычно, затем отправить изменения в ветку `main`:

```powershell
git add .
git commit -m "Обновление записей Хисуи"
git push
```

GitHub Actions сам соберёт и обновит сайт. Статус виден во вкладке Actions репозитория.

## Локальный просмотр

Нужны Python 3 и Node.js 22 или новее.

```powershell
python scripts/prepare_site.py
cd .site
npm ci
npx quartz build --serve
```

Сайт работает на [Quartz 4.5.2](https://github.com/jackyzha0/quartz/tree/v4), исходная версия `d25a6eabf96751ffca56f8a8139272def7a65041`. Лицензия движка находится в `.site/LICENSE.txt` и не распространяется автоматически на авторский мир.

Репозиторий и сайт публичные, включая тайны ведущего. Настройки Obsidian, кеши, посторонний проект Ноти и локальный ZIP до уборки не публикуются. Canvas доступны как исходные файлы; для чтения на телефоне есть текстовые расшифровки в `06 Справочник/Источники досок`.
