## Сайт

В `.site/` включён готовый Quartz **4.5.2**, исходная upstream-версия `d25a6eabf96751ffca56f8a8139272def7a65041`. Node.js 22+, Python 3.

- `scripts/prepare_site.py` копирует разрешённые разделы и вложения в `.site/content`, делает главную `index.md` и адаптирует ссылки. Корневые `CODEX.md` и `AGENTS.md` на сайт не копируются.
- `.site/quartz.config.ts`: русский интерфейс, baseUrl `noty-chan.github.io/hisuya`, отключённая аналитика и тяжёлая генерация OG-картинок.
- `.site/quartz.layout.ts`: компоновка меню, поиска и темы.
- `.site/quartz/styles/custom.scss`: небольшие настройки чтения и touch targets.
- В `.site/quartz/util/glob.ts` намеренно `gitignore: false`: генерируемый `.site/content` исключён из Git, но должен читаться сборщиком. Ограничения публикации задаются подготовкой и конфигурацией.
- `.github/workflows/pages.yml` собирает и публикует сайт после push в `main`.

Команды из корня:

```powershell
python scripts/prepare_site.py
Set-Location .site
npm.cmd ci
npx.cmd quartz build
```

Для просмотра: `npx.cmd quartz build --serve`. Не править генерируемые папки вручную.
