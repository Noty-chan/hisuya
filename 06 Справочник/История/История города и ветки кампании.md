# История города и ветки кампании

## Основание и рост

| Дата источника | Событие |
| --- | --- |
| 0 Г.Л. | Основание у Стены Апофеоза для её изучения. |
| 10–30 Г.Л. | Форпост становится исследовательским центром. |
| 30–50 Г.Л. | Формирование Великих Родов. |
| 50–80 Г.Л. | Создание Совета. |
| 80–100 Г.Л. | Рост маготехнических исследований и институтов. |
| 100 Г.Л. | Открытие манакристаллов. |
| 110–120 Г.Л. | Строительство Небесной Академии на парящих островах. |

Источник: [[01 Мир/История Хисуи.md|история]]. Расшифровка «Г.Л.», абсолютная текущая дата и события после 120 Г.Л. не заданы. Поэтому эти числа не используются для вычисления возрастов действующих персонажей.

## Предыдущая игра: петля

Повторение дня, Темпи в плену Родов, вмешательство Короля Пространства и варианты судьбы Боада описаны ретроспективно в раннем своде. Подробного полного журнала той игры нет. [[01 Мир/Ранние версии/Хисуя — ранний свод.md|ранний свод]].

## Ранняя кризисная кампания

1. Похищено Сердце; Темпи освобождена; вскоре исчезает Стена. Это порядок раннего свода, причинная цепочка не доказана.
2. Исчезают Ланнок и Арвел, город подвергается бомбардировкам, возникают демонические угрозы и политический кризис.
3. Первый игровой цикл: разведка «Рубежа-7», портал демонов, погоня за Джеком, нападение на Туманку, эльфийский договор снабжения.
4. Второй: освобождение Каина и Азазеля, поиск автоматонов, библиотека и подмена советника Джеком, охота на монстров, добыча божественного металла.
5. Итог второго: Туманка уничтожена, Шурирены ушли, «Заря» завершена, границы Пик закрыты, город переживает новую тяжёлую бомбардировку.
